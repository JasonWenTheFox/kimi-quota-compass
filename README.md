# Kimi 用量罗盘 / Kimi Quota Compass

Kimi 网页版会员用量面板（Tampermonkey 用户脚本）。

## 功能

- 月度额度池已用比例，及 Code / Chat / Agent 分类占比
- Kimi Code 5 小时 / 7 天窗口用量与重置时间
- 逐条额度流水（时间、功能、条目、消耗比例）
- 可校准的金额估算：百分比 × 用户设定的月度额度池总值，支持 CNY / USD

## 原理

脚本运行在已登录的 kimi.com 页面内，复用网页自身的登录态，调用 Kimi 前端使用的官方会员接口（`GetSubscriptionStats` / `ListBalanceActions` / `GetUsages`）读取本账号的用量数据，只做展示，不改写页面行为。官方接口只返回百分比；面板中所有金额均为按校准系数换算的估算值，**不是官方账单**。

## 校准方法

官方只提供百分比。想知道 1% 池子折合多少钱：用任意能在本地统计请求用量的第三方工具，取一条已知 token 数的请求，按公开价目算出它的等效成本，再在面板流水中找到该请求的消耗比例，然后：

```
月度额度池总值 = 请求成本 ÷ 消耗比例
```

把结果填进面板的"月度额度池总值"输入框。

K3 参考价目（每百万 token）：输入 ¥20 / 缓存命中 ¥2 / 输出 ¥100（$3 / $0.3 / $15）。缓存命中约节省 10 倍；不同模型或功能的池子扣减倍率可能不同，建议用与你主要用途同类的请求来校准。

## 说明与免责

- 本项目为非官方工具，与 Kimi / Moonshot 无关。所调用的内部接口随时可能变化并导致脚本失效。
- 面板中的金额与分类占比为估算或汇总结果（Code 占比来自官方比例，其余分类由流水汇总，可能受流水返回条数限制），仅供个人参考，不构成账单或消费凭证。
- 网页对话的流式响应本身不携带 token 用量（已实测验证），因此本脚本不提供网页对话的逐条 token 数，只有比例扣减。
