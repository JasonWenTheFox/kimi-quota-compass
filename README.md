# Kimi 用量罗盘 / Kimi Quota Compass

Kimi 网页版会员用量面板（Tampermonkey 用户脚本）。

## 功能

- 月度额度池使用比例，Code / Chat / Agent / Swarm 分类占比
- Kimi Code 5 小时 / 7 天窗口：使用比例、内部额度单位、重置时间
- 逐条额度流水（时间、功能、条目、消耗比例）
- 可校准的月池 PAYG 等价估算（CNY / USD 独立保存，不做汇率换算）

## 重要说明

- **官方会员接口不提供网页/会员侧的逐请求真实 Token 明细。** 面板中所有金额均为按你的校准系数换算的估算值，不是官方账单。
- 5h / 7d 窗口显示的 `used / limit` 是 Kimi 内部额度单位（quota units），**不是 Token**。
- 额度流水接口每次最多返回约 20 条近期记录。插件会在你打开 Kimi 页面时自动抓取、切回页面时立即抓取、前台期间每 5 分钟抓取，按记录 id 去重后累积保存在**本浏览器** IndexedDB 中（不跨设备同步）。长时间不打开 Kimi 页面仍可能漏抓；月度分类中"插件未捕获"一行即此类缺口。
- 月度总比例与 Code 占比使用官方接口数值；Chat / Agent / Swarm 等分类为本地累计结果。

## 校准方法

用任意能在本地统计请求用量的第三方工具，取一条已知 token 数的请求，按公开 K3 API 价目算出它的等效成本，再在面板流水中找到该请求的消耗比例：

```
月池 PAYG 等价值 = 请求成本 ÷ 消耗比例
```

公开 K3 API 参考价目（按每 100 万 token 计价，与上下文长度版本无关）：

| 项目 | CNY | USD |
|---|---|---|
| 输入（缓存命中） | ¥2 | $0.3 |
| 输入（缓存未命中） | ¥20 | $3 |
| 输出 | ¥100 | $15 |

- 缓存命中约节省 10 倍。
- `k3-256k` 没有单独的公开 API 价目；会员额度池中完整版 `k3` 的消耗官方约为 `k3-256k` 的 2 倍（面板中"K3 1M 等价"按此折算并以 ≈ 标注）。
- 不同模型/功能的池子扣减倍率可能不同，建议用与你主要用途同类的请求校准。

未校准时面板使用参考默认值并明确标注"未校准"；手动修改后显示"用户校准值"。

## 其他

- 界面语言跟随浏览器（中文 / English）。
- 数据默认只存本浏览器（IndexedDB + localStorage），不上传任何第三方服务器。
- `kimi.ai` 海外版域名为兼容性尝试，未实测。
- 本项目为非官方工具，与 Kimi / Moonshot 无关；所调用的内部接口随时可能变化导致失效。使用即表示理解以上限制，风险自负。MIT License。
